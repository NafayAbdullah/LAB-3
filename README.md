Lab 3 Task

Scenario: University Student Academic &amp; Scholarship Management System
You are working as a junior web developer for a university. The university wants to
enhance its existing student portal with a JavaScript-based Academic &amp; Scholarship
Management System.
You have already developed the webpage structure and styling in Lab 02 using
HTML, CSS, Bootstrap, Flexbox, positioning, pseudo-elements, and CSS effects.
Your task is to extend that existing webpage using JavaScript Fundamentals.

Objective
Develop a JavaScript-powered section in your existing Lab 02 website that can:
 store student information,
 calculate academic performance,
 determine grades,
 determine pass/fail status,
 evaluate scholarship eligibility,
 display the results dynamically.
You must use the JavaScript concepts covered in Lab 03.
